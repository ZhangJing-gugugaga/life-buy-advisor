# life-buy-advisor · 生活购置决策助手

一个帮你"买得不后悔"的 AI 决策技能，覆盖生活内各类购置：代步车、厨具、家具、租买房、床品、个人用品等全品类。

核心理念：**先定需求，再算经济，然后调研，用矩阵决策，最后给明确意见——而不是替你下单，也不会瞎编。**

---

## 它能做什么

- **代步车**：电动自行车 / 摩托、汽车（新车 / 二手）、通勤 / 家用 / 载物
- **厨房**：锅碗瓢盆、电饭煲、刀具、调料等厨具耗材
- **家具**：桌 / 椅 / 柜 / 沙发 / 床架
- **租买房**：租房 vs 买房的经济测算与决策
- **床品与个人用品**：床垫 / 被子 / 枕、伞 / 雨衣 / 拖鞋
- 以及任何"该不该买、买哪种、花多少钱"的生活类决策

## 核心方法：五环节 + 环节 0（网络兜底）

### 环节 0 · 工具可用性探测与网络失效兜底（最高优先级）

> 这是本技能防"瞎编 / 基于失败或空内容给错误建议"的底线。

1. **先探测**：进入调研前先发 1 次轻量 WebSearch；若返回错误 / 超时 / 空结果 / 被拦截（被墙），判定为"调研工具不可用"。
2. **知识型意见模式（降级分支）**：工具不可用时，仅基于技能**内置知识**（`category_guide.md` + `pitfalls.md` + `economic_analysis.md`）给方向性意见，且**必须**标注 `⚠️ 未联网验证`，明确告诉用户"关键参数与价格请联网后复查"。
3. **离线护栏（防编造具体型号）**：优先给「配置档位 + 价格带 + 品牌梯队 + 关键参数要点」层面的方向；如确需提具体型号，必须逐条标注"来自训练记忆、未联网验证、可能已停产 / 改款"，**严禁**输出"XX 是最值得买"式断言。
4. **硬禁令**：禁止把"工具故障"说成"该品类没信息"；禁止用训练记忆冒充"已调研结论"；禁止在工具不可用且无内置知识时强行给"推荐 / 不推荐"。

### 环节 1 · 需求拷问（先定需求不瞎猜）

grill-me 式考问：列出 3–6 个顶层决策分支（用途、预算硬上限、不可妥协项、可权衡项、现有约束、时间窗），逐个先给推荐答案再提问，明确区分**硬约束**与**软偏好**。

- 🔴 **CHECKPOINT 强约束**：必须把需求画像念给用户并等明确确认词，**确认前不得搜索、不得推荐**。
- **快速意见模式**：若用户说"别问了直接给建议"，基于 `category_guide.md` 默认典型场景给意见，但必须显式列出假设并标注"未确认需求，可能偏离"。

### 环节 2 · 经济测算

预算三档适配 + **TCO 总拥有成本** + 租买对比 NPV / break-even + 分期真实年化。大件 / 可分期 / 租买类必出经济测算卡。

### 环节 3 · 市场调研

WebSearch 多关键词独立源搜索，按 **Tier1/2/3 分级**、软文识别 checklist、多源共识（≥2 独立源）、参数交叉验证执行；对关键 Tier1 结论用 **WebFetch** 拉原文核验。

- ⚠️ **failover 区分两种"没结果"**：工具失败 → 走知识型意见模式；搜索成功但无共识 → 如实告知"公开数据不足"，并说明是"市场数据层面"而非"工具故障"。

### 环节 4 · 决策矩阵

加权打分（3–5 维度，用户赋权；用户不愿赋权则用默认权重模板）+ 敏感度检验，至多 3 个候选防选择过载。

### 环节 5 · 意见决策 + 避坑

给明确结论（推荐 / 考虑 / 不推荐）+ 每候选 ≥1 个真实缺点 + 避坑提醒 + 信息源透明。涉及食品 / 保健 / 人身安全（上牌合规、3C）先确认资质，未确认前不输出推荐。

## 为什么不会瞎编

| 风险 | 本技能的防线 |
|------|------|
| 需求没搞清就搜 | 环节 1 CHECKPOINT 强约束，确认前不搜 |
| WebSearch 失效 / 被墙 | 环节 0 探测 + 知识型意见模式降级，不假装搜到了 |
| 把"工具坏了"说成"没信息" | 环节 3 failover 显式区分两种"没结果" |
| 用训练记忆冒充已调研 | 环节 0 离线护栏 + 禁止清单 **A7 / A8** |
| 堆数据不决策 | 环节 4 加权矩阵 + 敏感度检验 |
| 软文 / GEO 投喂 | Tier 分级 + 软文 checklist + 多源共识 + 反隐性广告警示 |

## 安装（作为 WorkBuddy 用户技能）

把本仓库放到 WorkBuddy 的用户技能目录即可：

```bash
# 方式一：直接拷贝
cp -r life-buy-advisor ~/.workbuddy/skills/

# 方式二：git 克隆
git clone https://github.com/ZhangJing-gugugaga/life-buy-advisor.git ~/.workbuddy/skills/life-buy-advisor
```

重启 / 刷新 WorkBuddy 后，当用户表达购置、添置、换新、租还是买、哪款好、性价比、值得买、避坑、帮我拿主意等生活消费决策意图时即触发。
