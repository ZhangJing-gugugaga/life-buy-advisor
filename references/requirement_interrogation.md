# 需求拷问模板（grill-me 式）

> 原则：**先定需求，再搜。绝不瞎猜。** 每个分支先给推荐答案，再提问，等用户回应后才继续。
> 区分「硬约束」（不可妥协）与「软偏好」（可权衡）。

## 通用顶层分支（每次必过）

1. **用途与场景**：这东西主要解决什么具体问题？（先推荐一个典型场景，再确认）
2. **预算硬上限**：最多花多少？是否含配件/运费/安装？（先给该品类合理中档价作锚）
3. **不可妥协项**：哪 1–2 点是底线？（如：必须合规上牌 / 必须 E0 级板材 / 预算死卡 500）
4. **可权衡项**：哪些能妥协？（颜色、品牌、是否新款）
5. **现有约束**：家里已有啥？空间/水电/物业限制？已有物品能否复用？
6. **时间窗**：急用吗？能否等 618/双11/淡季？

## 各品类关键拷问（加载对应章节前先问）

### 代步车（电动两轮 / 汽车 / 二手）
- 通勤距离 & 路况？（城市平坦 vs 乡镇颠簸 → 续航/减震要求）
- 载物/载人需求？（单人通勤 vs 接送娃/拉货）
- 合规红线：当地能否上牌？是否需要驾照？（硬约束）
- 充电条件：有固定充电桩/家充吗？（无则燃油或换电方案）
- 新车 vs 二手：预算与风险承受？（二手省钱但需验车）

### 锅碗瓢盆 / 厨具 / 调料
- 炉灶类型：燃气 / 电磁炉 /  induction？（决定锅具材质兼容，硬约束）
- 人数 & 烹饪习惯：几口之家？常炒菜 vs 煮汤 vs 烘焙？
- 健康诉求：是否介意涂层？偏好不锈钢/铸铁/陶瓷？
- 收纳空间：厨房台面/橱柜够吗？（影响尺寸取舍）

### 家具
- 摆放空间实测尺寸？（先要用户量，再推尺寸，不靠估）
- 风格与现有家具是否搭？
- 材质底线：是否介意人造板？（介意则预算上扬）
- 是否需要上门安装/搬运？（老小区无电梯 = 硬约束）

### 租买房
- 计划持有/居住多久？（<3 年偏租，>7 年偏买，中间看 break-even）
- 首付能力 & 月供承受上限？（先算月供占收入比红线 ≤40%）
- 城市与通勤：工作地稳定吗？（不稳定则租更灵活）
- 隐性成本承受：物业费/维修/中介费？（买房后持续流出）

### 床品（床垫 / 被子 / 枕）
- 睡眠痛点：腰背痛？怕热？易过敏？（决定支撑/材质）
- 床架尺寸：1.5m / 1.8m / 定制？（硬约束）
- 季节：冬被 vs 夏凉被 vs 四季通用？
- 是否可机洗？（懒人偏好）

### 个人用品（伞 / 雨衣 / 拖鞋）
- 使用场景：通勤淋雨 vs 户外徒步 vs 居家？
- 便携优先级：要折叠塞包 vs 放门口？
- 特殊诉求：防滑？透气？反光安全？
