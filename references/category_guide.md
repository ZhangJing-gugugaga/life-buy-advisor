# 各品类选购要点与合理价区间参考

> 价区间随年份/地区浮动，仅作"预算适配"锚点，实际以调研为准。平替思路沿用产业带逻辑。

## 1. 锅碗瓢盆 / 厨具
- **锅**：材质（铸铁/不锈钢/涂层铝）、锅底厚度（≥3mm 受热匀）、手柄隔热、适用炉灶（电磁炉认磁性底）。
- **刀**：钢材（5Cr15 起步，8Cr/VG10 更利）、一体成型 vs 拼接、握感。
- **电饭煲**：IH  vs 底盘加热、内胆材质（备长炭/钢）、容量按人数（1–2人 3L，3–4人 4L）。
- **调料**：看配料表排序、钠含量、有无防腐剂；大包装单位价更低但注意保质期。
- **合理价（参考）**：炒锅 80–400；菜刀 50–300；电饭煲 200–1200；调料按需。
- **平替**：顺德厨具、阳江刀剪产业带直供常比贴牌便宜 30–50%。

## 2. 家具
- **桌/椅/柜**：板材（实木/颗粒/多层）、封边工艺（激光封边更耐潮）、五金（百隆/悍高）。
- **沙发**：框架（实木/板木）、填充（高密海绵/羽绒）、面料（科技布/真皮）。
- **关键参数**：尺寸（必量摆放空间）、环保等级（E0/E1）、承重、是否需自装。
- **合理价**：餐桌 500–3000；人体工学椅 800–4000；衣柜 1000–5000。
- **坑**：运费上楼/安装另收；色差；甲醛报告。

## 3. 代步车
### 电动两轮
- 续航（看真实车主冬季续航）、电池（锂电循环 vs 铅酸）、刹车（碟刹优于鼓刹）、上牌合规（新国标 25km/h/55kg 上限）。
- 合理价：国标车 1500–4000；电摩 3000–8000。
### 汽车（新车）
- 能源（纯电/插混/燃油）、续航/油耗、保值率、保养成本、保险。
- 合理价：代步小车 6–12w；家轿 10–20w；SUV 15–30w。
### 二手
- 车况（维保/出险记录、底盘、发动机）、里程、过户次数、是否营转非。
- 验车：第三方检测（如查博士）+ 试驾。

## 4. 租买房
- **租房**：地段（通勤时间）、户型、租期灵活、押金/中介费、隐性扣费。
- **买房**：得房率、公摊、物业、学区/配套、开发商资质、月供占收入比（≤40% 红线）。
- **决策**：持有 <5–7 年多偏租；>10 年多偏买（因地而异，见 economic_analysis.md）。

## 5. 床品
- **床垫**：支撑（独立袋弹簧/记忆棉）、硬度（按体重睡姿）、透气、可拆洗。
- **被子**：羽绒（含绒量）、蚕丝（纯度）、四季被 vs 子母被。
- **枕**：高度按睡姿（侧睡高、仰睡中、俯睡低）、材质（记忆棉/乳胶/羽绒）。
- **合理价**：床垫 1000–8000；冬被 200–1500；枕 80–600。

## 6. 个人用品
- **伞**：抗风看伞骨（纤维护/铝合金）、伞面（碰击布防水）、折叠便携。
- **雨衣**：透气膜（PVC 闷、EVA/TPU 透气）、反光条（夜间安全）、尺寸覆盖。
- **拖鞋**：浴室防滑看鞋底（橡胶纹路）、材质（EVA 轻但滑，橡胶稳）、是否外穿两用。
- **合理价**：伞 30–200；雨衣 50–300；拖鞋 20–150。
