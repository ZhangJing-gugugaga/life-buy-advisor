# 经济测算方法（本 skill 核心新增维度）

> 目标：把"买不买得起、买哪种更划算、持有多久才值"算清楚，而不是凭感觉。

## 1. 预算适配

先给该品类**合理价三档**（参考 category_guide.md）：
- 用户预算 < 低档 → 提醒"预算偏紧，可能要降配或等促销"
- 低档 ≤ 预算 ≤ 中档 → "甜区，选择最多"
- 预算 > 高档 → "可上高配/旗舰，注意溢价"

## 2. TCO 总拥有成本（大件耐用品必算）

```
TCO = 购置价
    + 耗材/配件（如电饭煲内胆、代步车轮胎）
    + 维护（保养/维修/保费）
    + 能源/持有成本（电费/油费/物业费/利息）
    − 残值（二手可收回部分）
```

**示例·电动自行车（持有 3 年）**
| 项 | 金额 |
|----|------|
| 购置 | 2500 |
| 电池更换(1次) | 600 |
| 保养/维修 | 300 |
| 充电电费 | 150 |
| 残值(3年后二手) | −800 |
| **TCO** | **2750** |

**示例·电饭煲（持有 5 年）**
| 项 | 金额 |
|----|------|
| 购置 | 400 |
| 内胆更换(1个) | 80 |
| 电费(每天0.3度×5年) | 270 |
| 残值 | −50 |
| **TCO** | **700** → 年均 140 |

→ 比"裸购价"更能反映真实花费，避免只看标价。

## 3. 租买对比（租买房 / 可租可买）

简版 break-even 思路（国内参数）：

```
买房年成本 ≈ 月供×12 + 物业费×12 + 维修计提 − 租金可省下的投资收益
租房年成本 ≈ 年租金 + 搬家/折腾成本
```

- 若 `买房年成本 > 租房年成本` 且你计划持有 < N 年 → 租更划算
- **break-even 月数**：房价中"多花的钱"被"每月省下的租金差"摊平所需月数
  - 粗略：break-even ≈ (首付机会成本 + 买卖税费) ÷ (月租金 − 月供差额相关)
  - 经验：国内多数城市 **持有 < 5–7 年租比买省**，>10 年买更稳（因地而异，需标注假设）

⚠️ 给出**持有 3 / 5 / 10 年**三档结论，并标注"未含房价涨跌预期"。

## 4. 分期真实成本

- **免息陷阱**："12 期免息"常暗含手续费/强制保险 → 算真实年化。
- **真实年化利率** ≈ `总利息 ÷ 平均占用本金 ÷ 年数 × 2`（近似，或让用户用银行 IRR）。
- **提前还款**：是否有违约金？违约金是否吃掉利息优惠？
- 结论格式："表面免息，真实年化约 X%，总多付 Y 元；若能手头现金拿去理财收益 > X% 则分期划算"。

## 5. 输出格式：经济测算卡

```
【经济测算卡】
预算适配：___（三档：低___/中___/高___）
TCO（持有N年）：___（购___+耗___+维___+能___−残___）
租买结论：持有<___年租划算 / >___年买划算（假设：___）
分期：名义___ / 真实年化___% / 总利息___
敏感区间：若持有变为___则结论___
数据可信度：已验证 / 部分估计（缺___）
```
