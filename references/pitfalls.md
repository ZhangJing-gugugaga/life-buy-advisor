# 避坑清单（反软文 / 反隐性广告 / 品类特有坑）

## 一、反隐性广告（2026 新坑，必读）

AI / 博主 / 测评的"种草式"推荐未必客观，常见操控手法：

1. **角色扮演诱导**：给 AI/博主预设"只推某品牌的资深发烧友"剧本，回答显得真诚客观，实为广告。
2. **GEO 投喂式优化**：商家批量发布"2026 最值得入手的 10 款 XX"软文，AI 一搜就抓到，整合进推荐。
3. **极端形容词堆砌**："绝了/封神/天花板/必入"，无具体参数与缺点。
4. **前 90% 讲痛点、最后 10% 突然推一个带链接的产品**。

**对策**（来自科技日报消费警示 + 本 skill 强制）：
- 逼 AI/自己**反向刁难**："除了 A 还有哪些？A 常见缺点是什么？" 答不出客观缺点 = 有鬼。
- 要求**多源 + 负面**，真正客观的推荐必列多个选项并讲缺点。
- 价格**独立验证**（比价工具/官网），"AI 说最低"不可信。
- 永远记住：**AI 只是工具，最终你拍板。**

## 二、软文识别 checklist（沿用 trusted_sources.md）

含 2 个以上信号 = 仅作辅助，不作核心依据：
- 未标注"赞助/合作/广告"但明显偏向
- 充斥极端形容词
- 结构前痛后推
- 账号近期密集推同品类、条条带链
- 评论区模板化好评、负面被删
- 只有主观感受、无参数/实测

## 三、品类特有坑

### 厨具 / 锅具
- 涂层脱落（特氟龙刮花后释放）→ 查是否有 FDA/国标食品接触认证
- "麦饭石/钛"营销词≠真实材质，认准基材（铝/不锈钢/铸铁）
- 虚假不粘：新锅都滑，看 3 个月后追评
- 调料：配料表排序（越前含量越高）、钠含量、添加剂

### 家具
- **甲醛**：认 E0/E1 等级与检测报告，避开"零甲醛"虚假宣传
- 板材虚标：实木颗粒≠纯实木，问清"框架/贴皮/填充"
- 物流坑：上楼费/安装费/偏远附加，下单前问清
- 色差：屏幕色 ≠ 实物，要线下或追评图

### 代步车
- **续航虚标**：标 100km 实际 60–70（低温/载重更缩）→ 看真实车主续航帖
- 二手事故车/泡水车：查维保记录、出险记录
- 上牌合规：当地对时速/重量/牌照的要求（硬约束，违规则不能上路）
- 电池循环：锂电循环次数 → 影响残值

### 租买房
- 租房：中介费/押一付三/隐性扣费（清洁费、家具损耗押金）
- 买房：公摊面积、得房率、物业费、维修基金、开发商资金链风险
- 租买误判：短期居住硬买 = 被绑定 + 交易成本吃掉收益

### 床品
- 支数虚标：40 支标 100 支常见 → 看克重/密度
- 填充物：羽绒含绒量、蚕丝纯度、记忆棉密度
- 可机洗：标"可洗"但要看是否缩水/结块

### 个人用品
- 雨衣：透气性差闷汗 → 看透气膜参数
- 伞：抗风看伞骨数量/材质（纤维护≠抗风），折叠伞便携但弱风
- 拖鞋：浴室防滑看鞋底纹路/材质（EVA 防滑一般，橡胶更稳）

## 四、红线（STOP）

- 🛑 **食品/保健品**：必须确认生产资质、执行标准、蓝帽子标识，不推三无
- 🛑 **人身安全相关**：代步车上牌合规、电器 3C 认证、家具阻燃 —— 未确认资质前不输出推荐
- 🛑 **医疗功效断言**：不对保健品/药品做"有效/治愈"判断，只陈述成分与批准文号
